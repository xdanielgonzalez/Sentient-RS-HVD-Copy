# Rust API docs (rustdoc)

The API reference for every workspace crate is generated by **rustdoc** and grafted into this
book under `api/` after the mdbook build. Build the full site locally with `just docs`
(rustdoc → mdbook → graft), or just the API docs with `just docs-api` (output in
`target/doc/`). The links below are live in the built book; on GitHub they resolve only after
a local `just docs` run.

**Coverage notes.** rustdoc is built with each crate's **default features**, plus a second
`cargo doc -p lib-net --features host` pass (its default feature set is empty, so the host
mesh/locate modules would otherwise be missing). `tools/tms-idl-codegen` (the host-only IDL
code generator) is **outside the cargo workspace** and is not covered here. `test-acceptance`
ships no lib or bin target — only a `harness = false` cucumber test — so rustdoc generates no
page for it.
